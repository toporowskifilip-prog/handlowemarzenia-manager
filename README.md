# HandloweMarzenia Manager

## Opis aplikacji

HandloweMarzenia Manager to prywatna aplikacja służąca do zarządzania ofertami sprzedażowymi na platformie Allegro.pl.

Aplikacja została przygotowana na potrzeby konta sprzedawcy **handlowemarzenia**.

## Funkcjonalności

- Tworzenie i edytowanie ofert sprzedażowych.
- Przygotowywanie tytułów, opisów i parametrów produktów.
- Tworzenie szkiców ofert za pomocą Allegro REST API.
- Publikowanie ofert po zatwierdzeniu przez użytkownika.
- Pobieranie informacji o ofertach i ustawieniach sprzedaży.

## Integracja

Aplikacja wykorzystuje Allegro REST API oraz autoryzację OAuth 2.0.

## Wersja

1.0 — rozwój i testowanie integracji.

## Przeznaczenie

Aplikacja jest przeznaczona do prywatnego użytku właściciela konta Allegro handlowemarzenia.
